# 本机维护

维护工具运行在 Windows PC。手机只使用安装包中的资料并直接访问配置的模型服务，没有需要长期运行的 7u 服务器。

## 第一次准备环境

在仓库根目录运行 `uv sync --locked`，随后双击 `tools/start_7u_maintenance.cmd`。默认模板在 `config/default.json`，本机路径和参与者映射放在被 Git 忽略的 `config/local.json`，覆盖默认值。

需要配置本机 QQ 加密数据库路径、读取所需密钥文件路径、语音原音目录及双方映射。不要把真实路径、账号或密钥改进默认模板。PC 工作库的 `self_qq` 是维护人，`partner_qq` 是收礼人；导出给 App 时交换一次，详见 [架构](architecture.md)。

模型 Key 和腾讯语音凭据在维护窗口输入，加密保存在本机。不要放入源码、命令参数或聊天截图。永久签名只创建或恢复一次，见 [Android 发布](android-release.md)。

## 三个入口

### 一键构建新版 APK

先让 QQ 同步到最新记录，并确保可用语音原音已下载到本机。QQ 可以保持打开；导入读取稳定快照，不写 QQ 源库。

输入完整版本号，例如 `0.1.260927`，点击构建。一次任务依次完成：

1. 备份工作库和旧资产，增量提取 QQ。
2. 自动转写新增待处理语音，并采用通过准入的结果。
3. 重建净化记忆包，生成全新每日短句并审核。
4. 递增内部构建号，正式签名、校验，再发布到 `releases/`。

下方持续显示四阶段进度与错误。没有独立聊天提取页面。必要步骤失败就停止；重试复用已经完成的语音，不需要重新逐条听审。全程持有维护锁，另一个窗口不能同时更新资料或发布。

### 按 ID 修复语音

从 App 的依据面板复制消息 ID，在此打开。窗口显示日期、说话人和当前文字；播放原音，实际听完后确认，再修改保存或明确舍弃。PC 页面中的“你”指维护人，“她”指收礼人。

人工修正和舍弃带审计记录，后续自动转写不覆盖。自动转写采用的文本标记为 `asr_accepted`，不冒充人工 `verified`；人工未听过的音频不能勾选听审。空转写舍弃，缺原音保留为资料缺口，不猜测补文。App 检索结果中的语音稿带语音来源标签。

修正写回 PC 资料，下一次构建并安装 APK 后手机才会更新。

### 更换 API Key

输入新 Key，填写完整版本，保存并运行同一条完整构建链。输入留空保留已有 Key，不会清空；旧手机安装不会热更新，需要覆盖安装新包。

腾讯语音配置放在构建页的折叠区域，不单独占用维护入口。

## 版本与每日短句

对外版本格式为 `major.minor.YYMMDD`，日期须真实。默认建议档案日期，也可手动填写；程序尊重合法输入，不把版本日期当成实际资料截止时间。输入不含 `+构建号`，内部 Android versionCode 自动递增。

每次完整构建生成全新短句池，目标 60 条；有限生成/审核后，15–60 条、问题/陈述/回忆各 3–20 条即可发布。每条含标点不超过 15 个 UTF-16 代码单元，并核对消息 ID、人物、日期、逐字引文和共同具体关键词；另用独立模型请求结合语境决定接受或拒绝。只保留明确接受项，不凑数、不放回拒绝项、不回退旧池。

每日候选只使用直接文字，不把自动语音误识别推上锁屏。自动审核仍不等于人工逐条验收，语义和趣味性可继续抽查。手机每天只读取最终池，不重新调用模型。

## 常见失败

| 现象 | 处理 |
| --- | --- |
| 另一个维护任务正在运行 | 等待完成，不手工删除锁文件 |
| QQ 快照不稳定 | 等待 QQ 同步稳定后重试；不要修改源库 |
| 语音服务失败或仍有 pending | 检查腾讯配置、网络和原音后重试；不跳过失败发布 |
| 每日短句不足或审核失败 | 查看本机日志后重试，保留旧安装包；不强行降低来源校验 |
| 手机模型余额不足 | 处理对应模型账户后重试；无需因充值重打包 |
| 手机密钥不可用 | 更换 Key 后构建、安装新版 |
| 手机网络/格式失败 | 问题保留供重试或修改，不会存成成功答案 |
| 答案已显示但保存失败 | 使用重试保存，不重复付费生成；不要立即强停进程 |

备份位于 `data/backups/`，语音与短句过程审计也留在 `data/`。这些内容可能包含私聊，不提交或外发。长期保管资料和永久签名需另做安全备份，Git 不替代私有资料备份。

## 同一流程的命令行入口

从仓库根目录执行：

```powershell
uv run python -m maintenance.build --version-name 0.1.260927
```

它和窗口构建使用同一流程。`sync`、单独短句生成及已审查资产打包等内部函数不是日常替代入口，勿用来绕过完整链路或发布校验。
