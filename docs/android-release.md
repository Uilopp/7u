# Android 私发发布

7u 通过发送 APK 私发。资料、提示词或模型 Key 更新，都要重新构建并覆盖安装；没有服务器热更新。

## 固定身份与环境

包名固定为 `com.sevenu.app`。当前已使用永久签名，不要重新生成另一份，也不要改包名。原 keystore、别名和密码必须安全备份；丢失签名后无法按原身份覆盖升级。

构建读取 `app/android/key.properties`，永久签名备份位于本机 `data/release-signing/`。迁移电脑时恢复原身份，不把配置和密钥提交 Git。只有真正首次部署、尚无已发布身份的环境，才运行：

```powershell
uv run python -m tools.setup_android_signing
```

需要匹配锁文件的 Python 环境、Flutter/Dart、Android SDK（compileSdk 37）和 Java 17；按工具提示准备 Android 构建依赖与许可证。调试构建不是正式发布，不向收件人发送 debug 包。

## 发布步骤

1. 在 PC 让 QQ 同步最新记录，确认语音原音路径可读；如发现错字，可先按消息 ID 修正。
2. 运行离线回归；任何数据、提示词或代码改动都需要相应验证。
3. 双击 `tools/start_7u_maintenance.cmd`，输入完整版本号后“一键构建新版 APK”；或从仓库根目录执行同一命令：

```powershell
uv run python -m maintenance.build --version-name 0.1.260927
```

4. 等待导入、转写、全新短句、记忆包和正式构建全部成功。记录本次产物路径、版本、SHA-256 和签名核验结果。
5. 在独立测试设备或保留数据的测试环境做覆盖升级验收，再发送 `releases/` 中本次成功产物。

维护流程读取加密配置，Key 通过临时定义文件进入构建，不放进命令参数；临时文件完成后清理。内部版本从当前配置和历史合法 APK 的实际 metadata 取最大值后递增。它校验包名、版本、正式证书及签名连续性，拒绝 debug 签名和旧构建产物；只在验证成功后发布完整新文件，不覆盖旧 APK。

内部 `app/build/app/outputs/flutter-apk/app-release.apk` 是构建产物位置，不是成功发布的凭据；失败时不要自行拿它替代正式成品。

## 版本

维护者填写 `major.minor.YYMMDD`，例如 `0.1.260927`。建议日期对应资料截止时间，但合法手动值不被改写；实际档案日期独立来自记忆包。输入不能含 `+`。

文件名可能为 `7u-0.1.260927+8.apk`；`+8` 是内部 versionCode，App 对外显示版本名称。相同版本名可用于同日修复，但内部编号必须更大。回答保存生成时版本，升级不改写旧答案版本。

现存 `+8` 是此前成品，本轮目录重整没有重建；当前工作树的提示词/代码可能不同，不保证旧包包含最新内容。发布审计必须检查实际 APK，而不是只查看工作树或旧报告。

## 验收清单

- 离线 Python 与 Flutter 测试、静态检查通过；真实模型测试须显式开启。
- 包名、版本、非 debug、永久证书连续性与设备兼容检查通过。
- APK 内记忆包、主提示词副本、每日短句与本次准备的文件一致；源资料逐项匹配。
- 没有合成测试资产、工作库、原音、私钥、腾讯凭据、DPAPI 文件或诊断日志混入包。
- 短句为本次全新池，满足数量、长度、人物、日期、原话和独立审核要求；审核记录留在 PC。
- 覆盖升级保留会话、答案、草稿和旧版本标签；先卸载不算升级验证。
- 首问、追问、换人物、新会话隔离、依据与语音标签、复制全文正常。
- 断网可读历史；失败问题可重试，技术错误不保存成虚构成功答案。
- HOME、锁屏、Activity 回收、通知拒绝、冷点通知、每日提醒及同日去重按 [通知说明](background-notifications.md) 验证。

`tools/qa/` 中的发布审计与显式模型诊断可辅助检查；须对本次产物运行，不将历史报告当作新包验收。

## 安装与更新

只发送最终 APK，不发送项目、数据库或配置。收件人按 Android 提示允许此次文件来源安装未知应用。后续同包名、同签名覆盖安装，不先卸载、不清除 App 数据。

旧 debug 签名安装与正式签名不兼容；若设备已有需要保留的对话，不要为解决安装冲突直接卸载。先确认实际签名和数据保留方案。

模型 Key 被编入 APK，可逆向提取；这是少量可信收件人的私发取舍。Git 忽略密钥只能保护仓库，不能把 APK 变成安全密钥容器。
